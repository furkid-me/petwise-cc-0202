# PetWise - LINE LIFF 寵物日記系統設計文檔

## 一、產品概述

PetWise 是一款基於 LINE LIFF 的寵物生活記錄應用，讓飼主能夠透過口語化的方式輕鬆記錄寵物的日常生活。

### 核心價值
- 📝 **口語化記錄**：自然語言輸入，AI 自動解析分類
- 🐾 **多寵物管理**：支援多隻寵物的獨立記錄
- 📊 **智能分析**：健康趨勢追蹤與提醒
- 💬 **LINE 原生體驗**：無需下載 APP，直接在 LINE 中使用

---

## 二、使用情境設計

### 情境 1：新用戶註冊與新增寵物
```
用戶: 打開 LIFF 應用
系統: 歡迎使用 PetWise！請先新增您的毛小孩 🐾
用戶: 點擊「新增寵物」
系統: 請輸入寵物資訊（名字、種類、品種、生日、體重）
用戶: 填寫「麻糬」、狗、柴犬、2020/05/15、8kg
系統: 太棒了！麻糬已經加入 PetWise 家族！
```

### 情境 2：口語化日記記錄
```
用戶: "今天麻糬早上吃了一碗飼料，下午帶去公園跑了半小時，回來喝了很多水"
系統自動解析:
  - 飲食記錄：早上吃了一碗飼料
  - 運動記錄：下午公園跑步 30 分鐘
  - 飲水記錄：喝了很多水（標記為「大量」）
```

### 情境 3：健康異常記錄
```
用戶: "麻糬今天拉肚子兩次，精神看起來有點差"
系統自動解析:
  - 健康記錄：腹瀉 2 次
  - 行為記錄：精神不佳
  - 系統提醒：建議持續觀察，如持續超過 24 小時請就醫
```

### 情境 4：醫療記錄
```
用戶: "今天帶麻糬去打疫苗，狂犬病疫苗，下次要一年後再打"
系統自動解析:
  - 醫療記錄：疫苗接種 - 狂犬病
  - 自動設定提醒：一年後提醒接種
```

### 情境 5：多寵物切換
```
用戶: "切換到小花"
系統: 已切換到小花（波斯貓）
用戶: "今天梳毛梳了 15 分鐘，掉毛有點多"
系統自動解析:
  - 美容記錄：梳毛 15 分鐘
  - 備註：掉毛較多
```

### 情境 6：查詢歷史記錄
```
用戶: "麻糬上週的飲食記錄"
系統: 顯示麻糬過去 7 天的飲食記錄列表與統計
```

### 情境 7：付費用戶 - AI 健康分析
```
用戶: "分析麻糬這個月的健康狀況"
系統:
  - 飲食穩定度：95%
  - 運動量趨勢：較上月增加 20%
  - 體重變化：維持穩定
  - 建議：目前狀況良好，建議維持現有飲食與運動習慣
```

## 四、記錄分類系統

### 主要分類
```
1. 飲食 (FOOD)
   - 主食（飼料、鮮食、罐頭）
   - 零食
   - 飲水
   - 保健品

2. 健康 (HEALTH)
   - 排泄（大便、小便）
   - 嘔吐
   - 症狀（咳嗽、打噴嚏、皮膚問題等）
   - 體重
   - 體溫

3. 活動 (ACTIVITY)
   - 運動（散步、跑步、游泳）
   - 玩耍
   - 訓練
   - 睡眠

4. 醫療 (MEDICAL)
   - 疫苗
   - 驅蟲
   - 健康檢查
   - 就診
   - 用藥

5. 美容 (GROOMING)
   - 洗澡
   - 梳毛
   - 剪指甲
   - 剪毛

6. 行為 (BEHAVIOR)
   - 情緒
   - 異常行為
   - 社交

7. 其他 (OTHER)
   - 一般記錄
   - 備忘
```

## 六、技術棧

### 前端
- **Framework**: Next.js 14 (App Router)
- **UI Library**: Tailwind CSS + shadcn/ui
- **State Management**: Zustand
- **LINE SDK**: @line/liff

### 後端
- **Runtime**: Node.js
- **Framework**: Next.js API Routes
- **ORM**: Prisma
- **Database**: PostgreSQL
- **Authentication**: LINE Login (LIFF)

### AI 服務
- **NLP**: OpenAI GPT-4 API
- **用途**: 口語化文字解析、智能分類、健康分析

### 部署
- **Platform**: Vercel
- **Database**: Supabase / PlanetScale
- **Storage**: Cloudflare R2 / AWS S3

## 七、API 設計

### 認證相關
```
POST /api/auth/line      - LINE 登入驗證
POST /api/auth/refresh   - 刷新 Token
```

### 用戶相關
```
GET  /api/users/me           - 取得當前用戶資訊
PUT  /api/users/me           - 更新用戶資訊
GET  /api/users/me/subscription - 取得訂閱狀態
POST /api/users/me/subscription - 訂閱/升級方案
```

### 寵物相關
```
GET    /api/pets              - 取得所有寵物
POST   /api/pets              - 新增寵物
GET    /api/pets/:id          - 取得特定寵物
PUT    /api/pets/:id          - 更新寵物資訊
DELETE /api/pets/:id          - 刪除寵物
```

### 日記相關
```
GET    /api/diaries           - 取得日記列表
POST   /api/diaries           - 新增日記（支援口語化輸入）
GET    /api/diaries/:id       - 取得特定日記
PUT    /api/diaries/:id       - 更新日記
DELETE /api/diaries/:id       - 刪除日記
```

### AI 解析
```
POST /api/ai/parse            - 解析口語化輸入
POST /api/ai/analyze          - 健康分析（付費功能）
```

### 提醒相關
```
GET    /api/reminders         - 取得提醒列表
POST   /api/reminders         - 新增提醒
PUT    /api/reminders/:id     - 更新提醒
DELETE /api/reminders/:id     - 刪除提醒
```

### 統計相關
```
GET /api/stats/overview       - 總覽統計
GET /api/stats/food           - 飲食統計
GET /api/stats/health         - 健康統計
GET /api/stats/activity       - 活動統計
```

### LINE Webhook
```
POST /api/webhook/line        - LINE Messaging API Webhook
```
